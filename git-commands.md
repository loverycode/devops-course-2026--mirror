git log — показывает историю коммитов (кто, когда, что менял, сообщение коммита). Используется, чтобы посмотреть, какие изменения были сделаны ранее.

git diff — показывает разницу между версиями файлов: между рабочей директорией и индексом, между индексом и последним коммитом и т. д. Используется, чтобы увидеть, что именно изменилось, но ещё не закоммичено.

git checkout — переключает между ветками или коммитами, а также восстанавливает файлы из истории (отменяет изменения в рабочей директории). Две основные задачи: «перейти на другую ветку» и «вернуть файл к предыдущему состоянию».

git merge — сливает изменения из одной ветки в другую. Обычно используется, чтобы влить готовую функциональность из отдельной ветки в основную (main/master).
